# Custom Password Generator

## Project Description

The Custom Password Generator is a Python-based web application developed as part of my Python Development Internship at Auspify Technologies.

It allows users to generate passwords by choosing the password length, character types, and number of passwords required.

## Features

- Generate passwords using alphabets, numbers, and special symbols.
- Choose a password length between 4 and 128 characters.
- Select automatic or manual password creation.
- Generate multiple passwords at once.
- Copy generated passwords using the Copy button.
- Validate user inputs.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Requirements

- Python 3
- Flask
- A web browser

## How to Run the Project

1. Open the project folder in VS Code.

2. Open the terminal.

3. Install Flask if it is not already installed:

   `python3 -m pip install flask`

4. Run the application:

   `python3 app.py`

5. Open this address in your browser:

`http://127.0.0.1:5000`
