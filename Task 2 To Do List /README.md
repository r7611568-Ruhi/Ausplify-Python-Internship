# Smart To-Do List

## Project Description
The Smart To-Do List is a Python-based web application developed using Flask, HTML, CSS, JavaScript, and SQLite. It helps users organize tasks, set deadlines, track progress, and manage daily activities.

## Features
- Add tasks with titles and descriptions.
- Set task priorities: High, Medium, and Low.
- Set due dates for tasks.
- View, edit, and delete tasks.
- Mark tasks as started or completed.
- Search tasks and filter them by status.
- Display task statistics on the dashboard.
- Show deadline reminders and overdue tasks.
- Track task creation, start time, completion time, and duration.
- Store tasks in an SQLite database.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Project Structure
- `app.py` – Flask application and backend logic.
- `templates/index.html` – Main dashboard.
- `templates/edit.html` – Edit-task page.
- `static/style.css` – Styling for the application.
- `tasks.db` – SQLite database created by the application.
- `Screenshots/` – Project screenshots.
- `To_Do_List_Demo.mov` – Project demonstration video.

## How to Run the Project
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install Flask using `pip install flask`.
5. Run the application using `python3 app.py`.
6. Open `http://127.0.0.1:5000` in your browser.
